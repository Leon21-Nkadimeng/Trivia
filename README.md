# About the project
I built a lightweight trivia website that lets anyone create a trivia game and invite others using a shareable room code; no login is required for either participants or hosts. When a host creates a trivia game, an admin code is generated for that trivia, and they are redirected to the manage trivia page immediately after creating a trivia. They are shown the details of the trivia, including a leaderboard. On the manage trivia page, they can stop the trivia at any time. Once a trivia is stopped, no one can participate.

# Tech stack: 
- React JS for the frontend
- Node.js/Express for the backend
- MySQL for the database
- Socket.IO for real time dashboard
- Jest for automated testing
